The existing CLI project contains no rebuild plan, `new-ui` directory, design research, prototypes, or design-system files. This plan records the required workflow without recreating those missing artifacts:

```text
Legacy analysis, one screen at a time
  → screen inventory

  → external UI/UX research
```

## Migration constraints

- Keep Expo's `package.json` and `package-lock.json` foundation.
- Do not migrate CLI native directories, generated configuration, build output, Gradle/CMake workarounds, or `CMAKE_NINJA_FORCE_RESPONSE_FILE`.
- Do not run Expo prebuild or local native builds as part of migration work.
- Validate migration with lightweight TypeScript, Expo Doctor, and Expo configuration checks.
