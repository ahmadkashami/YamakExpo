>

> to the active **`YamakExpoNew` (Expo + Expo Router)** app. **That migration is complete**, and
> `YamakExpoNew` is the only active project. Nothing here is a current instruction.

## Decision

`YamakMobileNew` is the superseded React Native CLI rebuild project. `YamakExpoNew` is now the only active rebuild project and uses the Expo architecture generated by `create-expo-app`.

The legacy `yamak-mobile` project is outside this migration. No legacy code or asset was migrated; it remains a later, screen-by-screen behavioral and visual reference.

`YamakMobileNew` contains the completed setup and Register Step 1 scaffold, plus uncommitted Register Step 2 visual work. It has no `docs/`, `docs/rebuild/`, rebuild plan, `new-ui/`, design research, prototypes, or partial design-system files. No document or design artifact was hidden in a stash, deleted path, or unreachable Git object.

## Production-code decision (state at migration time)

Expo Router replaces `NavigationContainer`, `AuthStackNavigator`, and the CLI entry point. At
migration time `/` redirected to `/register` and no auth group, authenticated group, tabs, drawer,
API, store, service, or future screen was introduced. All of those have since been added.

Register Step 1 remains the completed functional position. Register Step 2 remains paused: the copied logo is preserved, but the unapproved blue header is not implemented and the route contains only a minimal placeholder.

## Dependency decision

No dependency was added or removed. The existing Expo dependencies already cover Expo Router, safe areas, and status-bar behavior.

## Design status

No `YAMAK-DESIGN-001` or other design-system artifact exists in `YamakMobileNew`. The design workflow remains pending user review and approval; this migration does not start it.
